# 合规与安全边界

**本项目只处理本人采集或已获书面授权的材料。**

`webvault` 是采集产物之后的归档与证据整理层。它不判断目标站点是否允许采集，也不代替使用者取得授权；它假定输入目录中的内容已经由使用者合法取得，并把“如何保存、如何校验、如何回放”做成本地、可复现的流程。

## 1. 授权前提

使用本项目的前提是：

1. 材料由使用者本人采集，或已取得权利人的书面授权；
2. 采集与后续处理符合目标站点条款、robots 约定、适用法律与合同限制；
3. 使用者对材料中的个人信息、商业秘密和第三方内容拥有相应处理权限；
4. 使用者自行确定保留期限、访问范围和删除要求。

项目本身不提供任何授权判断、法律意见或合规认证。

## 2. 完全离线

运行期不发起任何网络请求：

- 不解析外部 DNS，不连接 CDN，不加载远程字体、脚本、样式或图片；
- Web 界面只监听回环地址 `127.0.0.1` / `localhost` / `::1`，默认端口 `5077`；
- `serve` 拒绝非回环 host；
- 页面资源全部来自本地包内模板与手写 `style.css`；
- SQLite 以 `mode=ro` 只读 URI 打开，浏览过程不写库；
- 源码不包含 `requests`、`httpx`、`urllib.request` 等对外 HTTP 调用路径；仅使用 `urllib.parse` 做 URL 规范化。

运行 `pytest`、`demo`、`build`、`audit`、`replay`、`manifest`、`diff` 都不需要网络。若运行环境本身缺少 Flask 等依赖，安装依赖需要网络，但这是环境准备，不属于程序运行期行为。

## 3. 不含真实抓取能力

本仓库没有爬虫、HTTP 客户端、登录态管理、代理池、限速器、robots 判定器或链接发现逻辑。它不会：

- 根据 URL 访问任何站点；
- 自动补全页面子资源；
- 执行页面脚本；
- 绕过访问控制、验证码或反爬机制；
- 对目标进行批量请求。

`replay` 生成的是 `response.http` 文件，供人工或本地脚本复核，不重新发起请求。

## 4. 无真实数据

仓库内所有 fixture 均由本地脚本确定性合成：

- 域名只使用保留 TLD：`site-a.test`、`site-b.test`、`site-c.test`；
- 不包含真实公司名、真实域名、真实 IP 地址、真实凭据或真实个人信息；
- 生成脚本 `scripts/gen_fixtures.py` 与 `scripts/gen_broken.py` 不访问网络；
- 测试只写入 `tmp_path`，不写入仓库跟踪文件；
- 文档中的示例同样只使用 `.test` 域名。

使用者导入自己的材料时，归档内容当然可能包含真实数据；仓库不会、也不应把这类数据提交回项目。

## 5. 不保存凭据

代码、测试、fixture 与文档中不出现密钥、token、访问口令、Cookie 或会话标识。导入器不读取环境变量中的凭据，也不为采集产物补写认证头。

若采集产物本身包含敏感头或个人信息，使用者应在采集侧完成必要的授权与最小化处理；本项目不会自动删除这些内容，因为静默改写会破坏字节保真与证据链。需要脱敏时，应在采集侧或独立的受控流程中完成，并明确记录处理行为。

## 6. 数据最小化与证据链

本项目只处理完成归档所需的字段：

- 目标 URL、采集时间、HTTP 状态与响应头；
- 响应体原始字节；
- 来源目录名与摘要信息。

`import` 只做校验与摘要；`build` 生成 WARC、CDX、SQLite；`audit` 只读校验；`replay` 按偏移或查询导出响应字节；`manifest` / `diff` 只比较元数据。整个过程不做全文索引、内容分析、画像或跨站关联。

为保持证据链：

- 记录 ID 与归档字节确定，相同输入得到相同输出；
- 审计报告包含每个归档的 SHA-256、declared/actual 长度与 digest 比对结果；
- 回放按物理偏移取记录，输出与归档中的 block 逐字节一致；
- manifest 记录每条响应的 digest、offset、状态、MIME 与时间；
- 出错时保留稳定错误码，不静默跳过或改写。

## 7. 使用者责任

使用者应负责：

- 确认采集行为与处理目的合法、授权充分；
- 限制归档目录和本地服务的访问范围；
- 在共享、导出或长期保存前评估敏感内容；
- 遵守保留期限与删除义务；
- 不把本项目当作规避访问控制、版权限制或隐私保护的工具。

## 8. 本地 Web 界面

`serve` 是只读调试视图，不是对外服务：

- 只绑定回环地址；
- 校验 `Host` 头，拒绝非白名单主机；
- 不提供上传、删除、写库、执行命令或代理请求功能；
- 响应体预览有长度上限，按十六进制或文本展示，不执行内容；
- 页面不引用任何远程资源。

如果将服务通过反向代理暴露到非回环网络，属于使用者的额外部署决定，不在本项目保证范围内，也可能带来未授权访问风险。

## 9. 声明

**本项目只处理本人采集或已获书面授权的材料。** 项目提供的离线、确定性、可审计能力用于合法归档与证据整理；不构成对任何采集行为、内容使用或数据处理的授权或许可。
